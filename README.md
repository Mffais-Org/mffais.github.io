## Getting Started

Install dependecies:

```bash
npm  install  --legacy-peer-deps
```

First, run the development server:

```bash

npm  run  dev

# or

yarn  dev

# or

pnpm  dev

# or

bun  dev

```

```bash
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
```
